# Живое восстановление глубины очереди

Одобренная реализация N2 для I03 из `docs/research/2026-10-09-next-improvements.md`.

## Требуемое поведение

- После загрузки нескольких страниц периодическое, фокусное и ручное обновление сохраняет намеренную глубину списка.
- Перед запросом очередь немедленно очищает защищённые строки; запрос получает новый список с начала и свежий cursor.
- Намеренная глубина хранится как одно число в состоянии очереди и переживает очистку при refresh, повторное обновление во время запроса и обычную ошибку с последующей попыткой. Загрузка следующей страницы увеличивает её по фактически загруженным строкам.
- Новая выдача заменяет прежний снимок. Старые строки и cursor не объединяются с ней.
- Для глубины до 100 используется один запрос с соответствующим `limit`. Backend принимает `limit` от 1 до 100.
- При глубине свыше 100 запрашиваются первые 100 свежих записей. Если свежий ответ содержит cursor, интерфейс явно сообщает, что продолжение нужно открыть кнопкой «Показать ещё».
- При ошибке обновления старые строки не возвращаются. Проверки identity/generation и обработки потери доступа остаются в силе.
- Фокус ссылки на обсуждение восстанавливается только если та же запись есть в свежем разрешённом ответе и фокус после очистки остался на `body`. Явный выход из очереди очищает цель; смена identity сбрасывает её. Поиск ссылки ограничен этой очередью.

## Граница и проверяемость

Backend, cursor-схема, original-grant правила, `private, no-store` и обработка `422 EMAIL_UNCONFIRMED` не меняются. Тесты состояния доказывают размер запроса, замену снимка, частичное восстановление при лимите и защиту от устаревших ответов. Typecheck проверяет TSX/API-интеграцию. Реальный пользовательский эффект и поведение фокуса в конкретных браузерах этими проверками не измеряются.

Явный pointer-down вне секции сбрасывает намерение восстановить фокус даже во время очищенного loading, когда blur уже невозможен. Обработчик удаляется при unmount. Глубина явного refresh-override сохраняется в metadata для перекрывающихся запросов.
