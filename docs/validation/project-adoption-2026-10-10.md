## Сквозная проверка

Проверено в Chromium на отдельной базе `fsp_qa_adoption_9c9f8a06`, только с вымышленными demo-аккаунтами. Сервер запускался из отдельной копии собранного JAR, frontend — через Vite.

1. Кандидат принял processing consent, загрузил текстовый PDF. Только выбранные город/навыки сохранились; имя и контакт остались прежними.
2. Необязательные ожидания 100–150 тыс. ₽/месяц gross/40 ч сохранились и пережили reload; видимость осталась hidden, подтверждённый грейд — null.
3. Финальный парсер извлёк подписанные имя, роль и один период опыта. Период `2021-04 — 2023-03` не стал телефонной подсказкой. Редактор не показывал JSON или технические ID навыков.
4. Два сохранения импортированного опыта вернули 200: после второго две записи, ID первой сохранён, server-only provenance в PATCH не отправлен, контакт/грейд/видимость не изменились.
5. Компания создала потребность (201), получила подсказки, подтвердила требования (200/v2). Аналитика показала два доступных synthetic junior-профиля в confirmed-fit; запрос v1 после изменения вернул 409. Малые зарплатные агрегаты были null/«неизвестно».
6. Обычный работодатель не увидел навигацию методиста; monitor API вернул 403.
7. Демо-методист создал вопрос (201), записал решение (200), добавил 10 **синтетических** наблюдений (200). Отчёт показал 7/10 и 0.7 только для synthetic, `human_results_claimed=false`. Это QA-факт арифметики и интерфейса, не человеческая экспертиза или качество задания.

## Границы результата

Импорт работает с текстовыми PDF, без OCR; извлечённые данные остаются черновиком для проверки. Контакты переносятся отдельным действием. Методист вручную создаёт вопрос по источнику; внешний LLM и автоматический retrieval не подключены. Экспорт `draft-v1` не заменяет сборку/проверку полного зачётного банка существующими инструментами.

Зарплатная сводка использует фиксированную видимую когорту специализации/грейда, скрывает малые счётчики и округляет медианы до 10 000 ₽. Точного счётчика для произвольной зарплатной вилки нет. Это ограничение предотвращает проверенный канал точного обратного вывода, а не обещание юридической готовности или формальная гарантия приватности.

Новые задания, review-аккаунты и метки pilot_record не доказывают участие людей, независимость экспертов, психометрическую валидность, реальный грейд или эффективность найма. Методика, live-банк и существующий release gate не изменены. Production/deploy и реальная ФСП-интеграция этим поручением не выполнялись.
