# Плавная анимация ФСП · Таланты

Дата: 10 октября 2026. Реализован сдержанный motion-слой в существующем интерфейсе. Ориентир — мгновенная обратная связь и прерываемое движение; фирменные цвета, типографика и рабочие карточки сохранены.

## Что изменилось

- Кнопки и ссылки действий сжимаются до 0.98 на нажатии и плавно возвращаются. Критически затухающая пружина сохраняет текущее положение и скорость при повторном вводе. Единый rAF работает только до остановки; React не обновляется на каждом кадре.
- Заголовки входят с небольшим смещением 6px; собственные панели диалогов — 5px/scale 0.985. Уведомления появляются мягко, а стрелка мобильного меню поворачивается. Короткие появления занимают 180–220ms.
- Native click, Enter/Space, отмена нажатия, фокус и закрытие диалогов сохраняют существующее поведение. Прозрачная область кнопки компенсирует сжатие визуального масштаба, сохраняя доступность исходного края.
- `prefers-reduced-motion` поддержан в CSS и runtime; смена настройки немедленно отменяет активное движение. Контрастные режимы сохраняют видимость текста и фокуса.

Изменённые исходники: `frontend/src/App.tsx` (только импорт и эффект установки), `frontend/src/styles.css` (один импорт); новые `frontend/src/motion.css`, `frontend/src/features/motion/press-motion.ts`, `spring.ts` и `frontend/src/features/motion.test.ts`. Новых зависимостей нет.

## Доказательства

После changed-files cleanup: **87/87 тестов**, включая **16 motion-тестов**; `npm run typecheck`, `npm run build`, `git diff --check` прошли. Для всех шести файлов выполнен установленный `omx code-intel lsp_diagnostics`: ноль диагностик. Этот инструмент использует `tsc --noEmit`; CSS отдельно разбирается Vite. В сборке остаётся предупреждение о существующем чанке больше 500kB. Отдельного lint-скрипта нет; AST-инструмент отсутствует, выполнен scoped `rg` анализ.

Браузерная проверка после перезапуска QA-сервера подтвердила один native action на mouse/Space, остановку пружины с восстановлением стиля, статическую кнопку/уведомление/индикатор в reduced motion. В настоящем экране работодателя проверены focus trap, Escape с немедленным удалением диалога и возвратом фокуса, сохранение черновика при переходе с 1280 на 390px, отсутствие горизонтального переполнения и transform/filter на предках модального окна.

Дополнительно до чистки проверены нажатие у края, drag-away без действия, native mobile disclosure и отсутствие приватных строк после отказа доступа. Их исходники после чистки не менялись. Немедленная очистка при refresh и отклонение устаревших ответов покрыты существующими queue-регрессиями в полном наборе. В наблюдаемом QA-трафике были только GET.

Сравнены 50 исходных хешей: 48 файлов не изменились; App/styles после удаления только добавленных motion-строк точно совпадают с начальным состоянием. Предыдущие незакоммиченные изменения сохранены.

Независимые native-агенты: **code-reviewer APPROVE**, **architect CLEAR**. Все семь инвариантов сопоставлены с кодом, тестами и независимым ревью. Первоначальный COMMENT из-за отсутствующего App-инструмента LSP записан в ledger; устранён через штатную CLI-поверхность того же установленного обработчика, без ослабления gate.

## Артефакты и границы проверки

Текущие результаты находятся в `local/apple-motion/2026-10-10/`: `cleanup-report.json`, `g003-verification.json`, `g004-verification.json`, `post-cleaner-baseline-proof.json`, `lsp-diagnostics.json`, `code-review.json`, `architect-review.json`, `invariant-audit.json`, `quality-gate.json` и браузерные записи/скриншоты. Старые корневые `.omx/ultragoal/*quality*` отчёты относятся к прежней задаче и не используются как текущие доказательства.

Браузер проверял dev-интерфейс с синтетическими локальными данными; production build проверен отдельно. Reduced motion проверялся через управляемый query-seam, без изменения настройки ОС. High-contrast/forced-colors проверены по CSS и независимому ревью. Диалог кандидата проверен по исходникам; интерактивная браузерная проверка проведена для диалога работодателя. Производительность на физических устройствах и восприятие людьми не измерялись.

Основа решения: [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion/), [Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/), [W3C reduced motion](https://www.w3.org/TR/mediaqueries-5/#prefers-reduced-motion). Это адаптация принципов к веб-продукту, а не заявление о равенстве с нативными интерфейсами Apple.
