# Сохранение контекста живой очереди

Итерация N2: после раскрытия страниц сохраняется только намеренная глубина и ID фокуса. Refresh сначала очищает строки/старый cursor, затем получает свежий ответ с начала при limit до 100 — существующая граница API. Перекрывающиеся обновления и временная ошибка не теряют глубину; потеря доступа/identity её сбрасывает. Больший объём восстанавливается частично с явной подписью и кнопкой продолжения.

## Проверка

Новые проверки воспроизвели отсутствие limit/флага глубины, затем потерю 10-строчного намерения при overlap/retry. Дополнительная проверка явного override воспроизвела падение 100→5 при втором refresh. После исправлений: 16/16 queue tests; полный frontend suite 71/71; TypeScript и production build прошли. Warning о JS chunk более 500 kB сохраняется; отдельного linter нет.

На изолированном стенде раскрыты две страницы по пять строк, после автоматического обновления осталось десять свежих строк. Наблюдался запрос limit=10 с начала. Новый шаг стал первым; две строки, отсутствующие в новом ответе, не вернулись; скрытое имя не отображалось. Во время задержанной загрузки наблюдалось ноль строк. Фокус восстановился к свежей строке с тем же ID.

Ревью и браузер воспроизвели ошибку: клик вне блока во время loading не создаёт нового blur, и фокус мог вернуться против намерения пользователя. Добавлен сброс ID при pointer-down вне секции, с очисткой обработчика при unmount. После: свежие десять строк, фокус остаётся на BODY после выхода; обычное восстановление действующей строки продолжает работать. Оба результата сохранены, без самообъявленного пользовательского эффекта.

## Граница доказательства

Backend/контракты/no-store/original-grant и canonical grade/ranking не менялись. Это frontend-проверка на синтетических ответах, а не доказательство фактического отзыва grant, человеческого качества оценки или эффективности найма. При намеренной глубине свыше 100 интерфейс объясняет частичное восстановление; прежние защищённые строки не остаются на экране. Ручная usability-проверка с людьми не проводилась.
