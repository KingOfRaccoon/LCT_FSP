## Сквозные проверки

В in-app браузере проверены настоящий API и отдельная локальная база с синтетическими demo-аккаунтами; доставка outbox выключена.

- Создание плана из двух этапов, 30 + 40 минут. Пустой этап блокирует отправку. Переключение необязательного плана сохраняет черновик.
- Изменение срока обратной связи через новую версию приглашения: первый снимок сохраняет 3 дня, второй содержит 4 дня.
- Кандидат видит полный план до принятия. После принятия общий шаг показывает действие, ответственную сторону и срок; редактора у кандидата нет.
- Компания сохраняет дату 10 октября 15:00 Europe/Moscow; UI, сервер и reload сохраняют один instant. Значение datetime-local читается из именованного поля FormData до асинхронного запроса.
- Параллельное QA-изменение вызывает 409. UI показывает новую серверную версию, сохраняет черновик и требует явного повторного сохранения.
- Сохранённый план в диалоге раскрывается и закрывается клавишей Enter. На ширинах 1280 и 390 px нет горизонтального переполнения.
- Отзыв разрешения оставляет кандидату архив. Компания по прежнему URL теряет доступ; общий шаг отсутствует в DOM.

Независимые проверки выявили и помогли исправить нормализацию невозможной даты, потерю черновика при переключении плана и переполнение expected_version. Версия запроса ограничена Int.MAX_VALUE и проверяется до преобразования; следующая версия при переполнении возвращает 409 без записи. После исправлений оставшихся замечаний P1/P2 не найдено. Отсутствие LSP-инструмента компенсировано свежими Kotlin/TypeScript compiler checks.

## Границы

Браузерный прогон не имитировал потерю сетевого ответа или управляемую задержку GET после отзыва; для этих случаев использованы unit/HTTP/static evidence. Клавиатурные и мобильные проверки не являются полным WCAG-аудитом. Сохраняется прежнее предупреждение Vite о chunk больше 500 kB.

Технические и синтетические проверки не доказывают рост конверсии, качество реального найма, человеческую валидность demo-банка или эксплуатационную готовность. Подробные локальные логи, снимки и QA-данные находятся в исключённом из Git каталоге local/hiring-journey/2026-10-09/.
