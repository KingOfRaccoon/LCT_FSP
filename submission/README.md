# Материалы для жюри

- FSP_Pitch.pptx — 10 редактируемых слайдов без внутренних заметок докладчика.
- FSP_Companion_Documentation.pdf — сопроводительная техническая документация; Markdown-источник рядом.
- FSP_Demo.mp4 — монтаж локального прогона с русскими титрами, H264, 2:36; все данные synthetic/demo.
- dependency-versions.txt — фактические версии компонентов.
- manifest.json — размеры, SHA-256 и проверенный статус пакета.

Код и запуск: корневой README.md. Документы отражают датированный срез локальной подготовки; рабочие исследования/источники, протоколы и заметки докладчика сохранены отдельно в local/. PPTX использует TDA Text/JetBrains Mono; шрифты не встроены. Границы synthetic/demo, ограниченного каталога и проекта согласий указаны в документации.
